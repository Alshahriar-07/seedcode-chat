# Seed Code Chat — Design System

## Visual identity

Seed Code Chat should feel:

- Premium
- Metallic
- Minimal
- Dark-first
- Futuristic without looking like a gaming dashboard
- Highly interactive
- Clean enough for long reading sessions

Avoid:
- Random floating particles
- Excessive neon
- Decorative noise
- Huge gradients everywhere
- Unreadable low-contrast text
- Excessive glassmorphism

## Palette

Primary:
Background #09090B

Surface #0D0F0E

Border #252927

Text #F5F5F5

Muted #7F8582

Brand #22C55E 



Accent may be used sparingly for active states and provider status.

## Layout

Desktop:
- Compact left sidebar
- Large centered conversation area
- Fixed/anchored composer
- Settings in a polished modal/drawer

Mobile:
- Sidebar becomes a drawer
- Composer remains easy to reach
- Model/provider selector becomes compact
- No horizontal overflow

## Chat message design

User messages:
- Clearly separated
- Compact bubble/card
- Easy to distinguish without oversized containers

Assistant messages:
- Reading-first layout
- Full-width content region
- Strong typography hierarchy
- Code blocks visually isolated

## Composer

The composer is the main interaction surface.

Include:
- Text area
- Attachment button
- Provider/model selector
- Send button
- Stop button while generating

The composer should expand vertically with content but remain bounded.

## Settings

Use sections/cards:

- Appearance
- AI Provider
- Model
- Generation
- Chat
- Data & Privacy
- About

Use controls instead of free-form configuration whenever possible.

## Responsive behavior

Breakpoints should be based on layout needs rather than specific device brands.

Touch targets should be comfortably tappable.

## Branding

Use the Seed Code wordmark subtly.

The interface should not imitate the exact branding or layout of ChatGPT, Claude, or Gemini.
